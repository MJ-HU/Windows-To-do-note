# Windows-To-do-note 电脑备忘录
在电脑下方任务栏显示的可滚动备忘录<br>
<img src="https://bee-reg-ab.imagency.cn/mr/202610/29/6ae30122dab2b.png"><br>
目前测试下来win10、win11可用<br>
鼠标双击左键 某个备忘事项，可以让该备忘消失，并显示后续的备忘事项，如果没有则取消显示，如下图中间的备忘没有了<br>
<img src="https://bee-reg-ab.imagency.cn/mr/202610/29/6ae301d368405.png"><br>
鼠标右击可以设置独立的自定义备忘，常规备忘以及远期备忘<br>
<img src="https://bee-reg-ab.imagency.cn/mr/202610/29/6ae30229041ce.png"><br>
解释：<br>
自定义备忘： 新增的及时备忘内容，鼠标双击后，会永远消失<br>
常规备忘：每天固定的备忘事项，鼠标双击后，无法消失，需要在设置中单独新增或者删除修改<br>
远期备忘：任务当天会显示，鼠标双击后，无法消失，需要在设置中单独新增或者删除修改<br>
在设置中，可以设置<br>
1. 是否滚动备忘<br>
2. 备忘显示的内容<br>
3. 显示位置<br>
4. 开机自动启动<br>
